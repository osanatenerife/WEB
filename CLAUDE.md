# Osana — notas para Claude

## Edición de vídeos de Instagram (Reels)

Cuando se pida editar vídeos para Instagram, seguir **siempre** el estilo de
`tools/reels/ESTILO.md` y montar con `tools/reels/build_reel.py` a partir de
una tabla de tomas en JSON (ejemplo: `tools/reels/reel-cuanto-llevo-en-mi-cara.json`).
Los vídeos originales los sube la dueña a los Releases de GitHub del repositorio.
